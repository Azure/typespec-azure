`@azureTokenAuthentication` requires an OAuth authentication model. An `entraDefaultScope` profile requires an enum of string resource values and a default audience member name. Each flow's existing scopes must equal the default resource followed by `/.default`; resources, including trailing slashes, are preserved exactly. A `challengeBased` profile requires a nonempty runtime contract and does not accept an audience enum.

Use one known-resource enum across language emitters. It is a catalog, not a restriction on native audience input. Native API shape, custom-input support, normalization, and override precedence belong to language emitters and their compatibility bindings.

`@azureServiceEnvironments` adds optional cloud endpoint defaults to the same audience-selection profile. Each environment must reference a named audience member and, when provided, an absolute HTTP or HTTPS endpoint without credentials or a fragment. A default environment must exist and use the authentication model's default audience. Audience selection alone does not derive or rewrite an endpoint; explicit client endpoints override environment endpoint defaults.
