# Arrays of literal values use the underlying wire type

## TypeSpec

```tsp
@service(#{ title: "LiteralArrays" })
namespace LiteralArrays;

enum Tier {
  Archive: "Archive",
}

model Preferences {
  storageAccountAccessTierPreferences?: "Archive"[];
  numericValues?: 1[];
  booleanValues?: true[];
  enumValues?: Tier.Archive[];
  nestedValues?: "Archive"[][];
}

@route("/preferences")
@post
op create(@body preferences: Preferences): Preferences;
```

# Literal array elements honor the by-value option

## Options

```yaml
slice-elements-byval: true
```

## TypeSpec

```tsp
@service(#{ title: "LiteralArrays" })
namespace LiteralArrays;

model Preferences {
  storageAccountAccessTierPreferences?: "Archive"[];
  nullableValues?: ("Archive" | null)[];
}

@route("/preferences")
@get
op read(): Preferences;
```
