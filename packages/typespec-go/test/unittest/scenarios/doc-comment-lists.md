# Bullet and numbered lists in doc comments are rendered per the Go doc convention

## TypeSpec

```tsp
@service(#{ title: "DocLists" })
namespace DocLists;

/**
 * This tests:
 * - Simple bullet point. This bullet point is going to be very long to test how text wrapping is handled in bullet points within documentation comments. It should properly indent the wrapped lines.
 * - Another bullet point with bold text.
 * - Third bullet point with italic text.
 *
 * Steps to follow:
 * 1. First step with important note.
 * 2. Second step with emphasis.
 * 3. Third step.
 */
model BulletPointsModel {
  /**
   * A property whose documentation contains a list:
   * - one
   * - two
   */

}

@@access(DocLists.BulletPointsModel, Access.public);
@@usage(DocLists.BulletPointsModel, Usage.output);
```
