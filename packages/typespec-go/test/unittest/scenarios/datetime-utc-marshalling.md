# Optional RFC3339 utcDateTime header/query params and an array model field are all coerced to UTC

RFC3339 is the only offset-preserving datetime format, so `utcDateTime` values
encoded as RFC3339 must have `.UTC()` applied before serialization. This single
operation exercises optional (pointer) header and query params plus a body model
whose field is an array of `utcDateTime` (pointer elements by default).

## TypeSpec

```tsp
@service(#{ title: "DateTimeUTC" })
namespace DateTimeUTC;

model Schedule {
  timestamps: utcDateTime[];
}

@route("/schedule")
@put
op put(
  @header("x-since") @encode(DateTimeKnownEncoding.rfc3339) since?: utcDateTime,
  @query @encode(DateTimeKnownEncoding.rfc3339) filter?: utcDateTime,
  @body body: Schedule,
): NoContentResponse;
```

# With slice-elements-byval, array elements are coerced to UTC inline (no nil check)

When datetime slice elements are stored by value, the marshaller applies `.UTC()`
inline rather than allocating a nil-checked temporary.

```yaml
slice-elements-byval: true
```

## TypeSpec

```tsp
@service(#{ title: "DateTimeUTC" })
namespace DateTimeUTC;

model Schedule {
  timestamps: utcDateTime[];
}

@route("/schedule")
@put
op put(@body body: Schedule): NoContentResponse;
```
