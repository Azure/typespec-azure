# `@@clientOption` emitContentTypeHeader keeps the literal Content-Type header in the response

## TypeSpec

```tsp
@service(#{ title: "ClientOption" })
namespace ClientOption;

@get
@route("/emit-content-type-header-decorator-1")
op emitContentTypeHeaderDecorator(): {
  @header
  contentType: "application/json";

  @body
  body: string;
};

@get
@route("/emit-content-type-header-decorator-2")
op emitContentTypeHeaderNoDecorator(): {
  @header
  contentType: "application/json";

  @body
  body: string;
};

#suppress "@azure-tools/typespec-client-generator-core/client-option" "response envelope retains content-type header"
@@clientOption(emitContentTypeHeaderDecorator, "emitContentTypeHeader", true, "go");
```

# Same thing but set at the emitter level so impacts all operations.

```yaml
emit-content-type-header: true
```
